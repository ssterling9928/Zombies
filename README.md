## 🚀 About This Project

This repository contains the complete source code for my zombie prototype game. This is a prototype zombie game I'm building in Unreal Engine 5.7.4. My main goal with this project is to experiment with game mechanics and AI.  Eventually in the future, I plan to make this a full featured game. 

## 🛠️ Tech Stack

This project was built using a modern, performance-focused tech stack:

| Technology | Purpose |
| :--- | :--- |
| **Unreal Engine** | Core game engine for developing the game. |
| **C++** | Main programming lanugage used for scripting. |

## ✨ Key Features

- **Custom Built Classes:** Working in C++ for all character and zombie classes. 
- **Arcade Style Zombies:** Assets purchased from the fab store.  ToonZombies - Be sure to check them out here: https://www.fab.com/listings/66f4a2f4-b04c-43d8-9a33-5e3fba1bb0ad
- **Ready to Implement Weapons:** Assets purchased from the fab store.  Not Implemented just yet.
